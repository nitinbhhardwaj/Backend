About This Project

Welcome to our Express.js and File System (FS) Module project. This project demonstrates how Node.js can be used to create a simple web server and serve HTML pages dynamically.

What We Are Learning

In this project, we are exploring Express.js for handling routes and the Node.js File System module for reading and serving HTML files.

Technologies Used

  • Node.js
  • Express.js
  • File System (FS) Module
  • HTML

Project Objective

The main objective of this project is to understand how a backend server communicates with different web pages using routes and how files can be accessed using the FS module.
